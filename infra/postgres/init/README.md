# infra/postgres/init

SQL-скрипты, которые Postgres выполняет при первой инициализации тома
(`/docker-entrypoint-initdb.d`). Выполняются в алфавитном порядке и **только один раз** —
на пустом томе. Изменения после этого делаются миграциями, а не правкой этих файлов.

Наполняется задачей **#2 (Схемы БД + RLS)**:
- `01_extensions.sql` — расширения (pgcrypto для токенов шеринга #29)
- `02_schema.sql` — таблицы из PRD §10 + `report_shares`, `chat_threads`, `chat_messages`
- `03_rls.sql` — включение RLS и политики по `tenant_id`, отдельная политика
  для доступа по токену публичной ссылки (единственный санкционированный обход RLS)

На задаче #1 каталог существует и монтируется — это часть контракта compose.
