# Интерфейс — что готово и как посмотреть

Собран на мок-данных, без бэкенда. Проверено: **0 ошибок типизации** (TypeScript,
strict). Полная сборка Next.js — на вашей стороне.

```bash
npm install          # первый раз долго: firebase-tools в devDependencies тянет 1000+ пакетов
npm run dev          # → http://localhost:3000
```

Если ждать install не хочется, `firebase-tools` можно выкинуть из
`apps/web/package.json` — в проекте он не используется, остался от прежнего шаблона.

## Экраны

| Путь | Что показывает |
|---|---|
| `/` | Проекты: список прогонов, статус, балл |

| `/personas/p-01` | **Полная карточка персоны** — все 8 категорий DNA |

| `/runs/task-8f21/chat` | Чат: аналитик и допрос персоны |
| `/prompts` `/portraits` `/settings` | Промпт-студия, портреты, настройки |

## Решения, которые видно в интерфейсе

**Карточка персоны показывает всё.** Ваш запрос — «кликнуть и увидеть все её
характеристики». Показаны все 8 категорий DNA, а не парадное подмножество из восьми
полей, как было в PRD. Смысл продукта в том, что персона не выдумана на ходу, а имеет
задокументированный профиль; если карточка показывает восьмую часть, проверить это
утверждение нельзя. Пустые поля не прячутся — видно, что данных нет.

**Каждое суждение имеет опору.** Ответы персон и реплики чата сопровождаются
таймкодами. Средний балл всегда раскрывается до конкретной фразы конкретной персоны —
иначе агрегат ничем не отличается от догадки.

**Разброс показан на шкале.** При перекрытии > 1 на полосе балла затемнена зона
min–max. Одно число без разброса создаёт ложное ощущение точности.

**Материал маркирован как прогноз.** Плашка на отчёте говорит прямо: это не опрос живых
людей. При перекрытии 1 там же написано, что разброс не измерялся.

**Диалог шеринга проговаривает последствия.** Ссылка работает без логина — то есть это
обход изоляции арендатора. Пользователь должен знать это до нажатия, поэтому TTL
выбирается явно, а не прячется в умолчаниях.

**Гео «иные НП» предупреждает.** При выборе этой группы в визарде появляется
предупреждение: в корпусе 0 записей из 165, персоны будут без заземления.

**Чат — два собеседника, а не одна фича с настройкой.** Аналитик видит весь срез;
персона видит только свой профиль, видео и свои прежние ответы. В интерфейсе это
написано текстом, потому что от этого зависит доверие к ответу.

## Что это ещё не

Мок-данные вместо API, локальный `useState` вместо XState и черновиков, имитация
прогресса вместо SSE. Всё это подключается на задачах #5–#21 и не меняет разметку.
Числа в моках подобраны по реальному корпусу (overall 7.34, acting 8.12, перевес 35–44),
чтобы вёрстка не поехала на первых настоящих данных.

Формально задачи #6–#12, #21 в графе остаются `pending`: интерфейс без бэкенда не
проходит свои критерии приёмки.
