# AGORA — синтетические фокус-группы на AI-агентах

Мультиагентная система, которая по социодемографическим параметрам генерирует
синтетическую аудиторию (цифровых двойников зрителей), «показывает» им видеоконтент
и собирает оценки — цифровой аналог офлайн фокус-группы.

Оценка ролика по 5 критериям (шкала 1–10): **общее впечатление, сюжет, игра актёров,
музыка, качество съёмок.**

> Это **объединённый репозиторий** (foundation) на базе трёх прототипов
> (`agora`, `agora-12-main`, `Agora-latest`). Каркас — Next.js. Полный разбор и ТЗ
> см. в [`docs/`](./docs). Дорожная карта агентов (Orchestrator, Persona DNA,
> изоляция респондентов, QA, Analytics) — в ТЗ v0.2.

## Стек

- **Next.js (App Router) + TypeScript + Tailwind** — UI и серверные route handlers.
- **LLM**: OpenAI-совместимый провайдер для текста + **Google Gemini** для нативного
  анализа видео (Files API). Провайдер и модели настраиваются через env.
- **Персистентность**: localforage (браузер) на MVP; перенос на Postgres — по ТЗ.

## Архитектура (важно про безопасность)

Все вызовы LLM выполняются **только на сервере** (`lib/ai-server.ts` + `app/api/*`).
Клиент (`lib/ai.ts`) — тонкая обёртка, которая ходит в свои route handlers через
`fetch` и **не содержит ключей**. Ключи берутся исключительно из переменных окружения.

```
Браузер (страницы 'use client')
  → lib/ai.ts (fetch, без ключей)
    → app/api/* (route handlers, runtime=nodejs)
      → lib/ai-server.ts  →  OpenAI-совм. API / Gemini Files API
```

### API-роуты

| Роут | Назначение |
|------|-----------|
| `POST /api/audience` | генерация синтетической аудитории |
| `POST /api/simulate` | симуляция ответов на анкету |
| `POST /api/report` | агрегированный отчёт |
| `POST /api/chat` | чат с фокус-группой |
| `POST /api/news-context`, `/api/news-analysis` | новостной контекст и реакция |
| `POST /api/upload`, `/api/upload-url` | загрузка видео в Gemini Files API |
| `POST /api/research/run` | нативный видео-анализ + отчёт (Gemini) |

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить ключи
npm run dev                  # http://localhost:3000
```

Переменные окружения — см. [`.env.example`](./.env.example).

## Статус

Foundation-версия: единый каркас, серверный LLM-слой, чистые ключи, портированный
видео-бэкенд. Настоящие агенты ядра (Orchestrator / Persona DNA с Big Five /
изоляция / QA / Analytics) строятся по этапам — см. `docs/AGORA_Анализ_репозиториев_и_ТЗ_v0.2.md`.
