# Раздаточный лист — инициализация проекта с ИИ-агентами

Одна страница. То, что стоит унести с лекции.

---

## Главное

**Агент не помнит вчерашний день.** Всё, что не записано в репозиторий, для
следующей сессии не существует. `CLAUDE.md` и `docs/` — это не оформление, это
память проекта.

**Правило без цены не соблюдается.** Пишите так: что нельзя → почему → что
вместо → чем это уже обошлось.

**Задача без критерия проверки не имеет окончания.** Каждый промпт заканчивается
строкой «Проверка: …».

---

## Скелет проекта

```
CLAUDE.md          протокол для агентов — читается первым
README.md          как запустить — для человека
.claude/
  agents/          специализированные подагенты
  commands/        слэш-команды: процедура, записанная один раз
  hooks/           перехват действий (линт перед коммитом)
docs/
  ARCHITECTURE.md  где что лежит и почему
  HANDOFF.md       состояние проекта прямо сейчас
  TEST_case.md     что увидеть глазами, чтобы поверить
src/
  app/             роутинг; loading.tsx, error.tsx, not-found.tsx обязательны
  components/ui/   примитивы shadcn — руками не правим
  components/…/    компоненты продукта
  lib/server/      база, секреты, внешние API — только сервер (server-only)
  lib/env.ts       валидация окружения через zod
tasks.json         граф задач: blockedBy, cdd, acceptance
```

## Порядок, который экономит переделки

```
ТЗ → технологии → граф задач → файловая структура → код
```

Чаще всего пропускают граф задач. Результат — проект, где всё начато и ничего
не закончено.

---

## Четыре части любого промпта

**Что** сделать · **где** (файлы) · **чем** (версии и библиотеки) · **как
проверить**.

> Подключи shadcn/ui поверх Tailwind v4. Примитивы в `components/ui/`, руками не
> правим. Добавь button, card, dialog, skeleton. Тёмная тема, цвета через
> `@theme` в globals.css. **Проверка: `pnpm build && tsc --noEmit` — чисто.**

---

## Четыре состояния экрана

```
загрузка → пусто → ошибка → данные
```

Три первых забывают. Экран, нарисованный только для «данных», выглядит сломанным
ровно тогда, когда пользователю тяжелее всего.

---

## Работа по референсу — три шага

1. **Забрать** страницу (Firecrawl).
2. **Разобрать в описание системы**: сетка, шкала отступов, типографика,
   палитра, набор компонентов. ← этот шаг пропускать нельзя.
3. **Собрать своё** на своём стеке по описанию.

Структура и ритм — общее ремесло. Тексты, изображения, логотипы и фирменный
стиль — чужая собственность.

## Знания модели устаревают

Tailwind v4 ушёл от `tailwind.config.js` к `@theme` в CSS. React Router v7 сменил
API. Агент без актуальной документации уверенно напишет прошлогодний код — и это
худший вид ошибки, потому что он выглядит правильным.

```bash
claude mcp add context7 -- npx -y @upstash/context7-mcp
```

## Секреты

Всё, что попало в переписку, **скомпрометировано**. Удаление сообщения ничего не
отменяет — нужен перевыпуск.

Узкая проверка хуже отсутствующей: сканер, который смотрит семь расширений,
бывает зелёным при живом пароле в дереве.

## Три ошибки, которые дорого стоят

| Ошибка | Почему дорого | Защита |
|---|---|---|
| Зависимость с нативным модулем | собранный на Linux пакет ломает запуск на macOS | брать WASM-аналог; проверка в CI |
| Импорт внутри функции без объявления в зависимостях | образ собирается, сервис healthy, падение — при первом обращении | тест: разобрать импорты через AST, проверить, что каждый разрешается |
| Правило в комментарии вместо теста | временное решение живёт вечно, потому что никто не помнит о нём | к каждому исключению — красный тест, пока оно в силе |

Общее: **ошибка, которая проявляется поздно, дороже той, что ломает сборку.**

## Проверка качества `CLAUDE.md`

Новый агент в чистой сессии, прочитав только этот файл, сделает задачу без
уточняющих вопросов?

Если что-то приходится объяснять в чате повторно — это не слабость модели.
Это отсутствующий абзац, и написать его нужно сразу, пока понятно, какой именно.
