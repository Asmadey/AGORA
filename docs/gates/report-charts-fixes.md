OWNS: apps/web/lib/report-survey-charts.ts, apps/web/lib/report-survey-charts.test.ts

Scope: два дефекта чтения, найденные третьим независимым ревью в модуле,
влитом в тот же день.

- [x] G1: размер среза берётся из охвата, а не из числа ответивших
  CHECK: npm test --workspace apps/web
  EXPECT: /# fail 0/
  CWD: .
  EVIDENCE: до правки `expected: 25, actual: 1` — порог показа применялся к
      числу ответивших, и срез из двадцати пяти человек прятался целиком,
      стоило ответить одному. Подпись при этом сообщала «срез содержит
      1 персону» про пятерых.

- [x] G2: числа среза матрицы находятся у своих вариантов
  CHECK: npm test --workspace apps/web
  EXPECT: /# fail 0/
  CWD: .
  EVIDENCE: до правки `expected: 0.5, actual: undefined` — поиск шёл по зашитым
      `m-1` / `y-1`, и у матрицы, заведённой оператором, посчитанный воркером
      срез не находился: измеренное значение выглядело неизмеренным.

- [x] G3: веб собирается и проверяется типами целиком
  CHECK: npx tsc --noEmit && npm run build

  EVIDENCE: `stats.base ?? stats.n` — у отчётов, снятых до появления `base`,
      другого числа нет, и поведение остаётся прежним. Это записано
      комментарием в коде, а не только здесь.
