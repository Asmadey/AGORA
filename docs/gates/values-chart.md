# Ворота: график ценностей аудитории

Эти ворота проверяют наблюдаемый результат задачи: числа, состояние малой
выборки, единый компонент и поведение сетки на узком экране. Они не заменяют
полный прогон проекта из `CLAUDE.md`.

## G1. Доли по персонам

CHECK: `npm test --workspace apps/web`

EXPECT: тесты `values-chart.test.ts` подтверждают, что 30 из 40 персон с
«Крепкая семья» дают ровно 75 %, а рядом видна доля источника.

## G2. Возрастное взвешивание источника

CHECK: `npm test --workspace apps/web`

EXPECT: тест передаёт набор только с возрастом `60+` и получает значения из
столбца `60+`, а не из столбца `всего`.

## G3. Малая выборка

CHECK: `npm test --workspace apps/web`

EXPECT: набор из 5 персон возвращает состояние малой выборки и текст, который
объясняет, что доли шумят на маленьком числе наблюдений.

## G4. Один компонент в двух местах

CHECK: `npm test --workspace apps/web`

EXPECT: исходник страницы набора и `ReportBody.tsx` импортируют один и тот же
`ValuesChart`, а `SurveyValuesChart` остаётся отдельным компонентом вопроса 8.

## G5. Две колонки без сжатия блока заземления

CHECK: `npm test --workspace apps/web`

EXPECT: контейнер графика и блок «Заземление на датасет» находятся в одной
адаптивной сетке, у которой одна колонка на ширине 375 px и две на широком
экране; у сетки нет горизонтального переполнения.

## G6. Полный веб-гейт

CHECK: `cd apps/web && npx tsc --noEmit && cd ../.. && npm run lint && npm run build`

EXPECT: типы, линт и production-сборка завершаются с кодом 0.
