# Ворота: полярность эмоций в вопросе 7

Ворота проверяют два показателя Приложения 2: долю респондентов, испытавших
только положительные эмоции, и долю респондентов, испытавших только отрицательные
эмоции. Обе доли используют размер охвата как знаменатель.

## G1 - Расчёт по наблюдаемому узлу конвейера

CHECK: `env -u OPENAI_BASE_URL -u OPENAI_API_KEY -u AI_MODEL python3 -m pytest -q tests/test_emotions_polarity.py`

EXPECT: тест проходит и проверяет только положительный ответ, только отрицательный
ответ, смешанный ответ, служебный вариант и полный пропуск вопроса 7 через
`survey_tally`.

## G2 - Веб-читатель сохраняет ноль и подавленный срез

CHECK: `npm test --workspace apps/web -- --test-name-pattern="полярност|эмоци"`

EXPECT: тесты проходят; измеренный ноль остаётся `0`, а `null` у подавленного
среза остаётся прочерком, без подстановки общего значения.
