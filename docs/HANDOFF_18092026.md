## 3. Кодекс: запускай его, это прямое требование владельца

Владелец просит делегировать **максимум** и параллельно. Рабочая команда:

```bash
codex exec --cd /private/tmp/AGORA-<имя> \
  --add-dir /Users/asmadey/AntiGravity/AGORA/.git \
  -o <файл-отчёта> "$(cat <файл-задания>)"
```

**`--add-dir` на `.git` основного репозитория обязателен.** Без него Codex падает

worktree лежат вне его области записи. С этим флагом он коммитит сам — проверено
сегодня трижды.

Конфиг: `~/.codex/config.toml`, `model_reasoning_effort = "high"`.

Что важно знать про него:

- В каждом задании пиши раздел **«Чего нельзя терять»** (§11.9). Без него он

## 4. Браузер: канал поднят, но сессии в нём нет

Владелец просил прокликать сценарии. Расширение Claude in Chrome **не подключается**
(живёт в основном профиле). Порт `9222`, на который он указывал, отдаёт **404 на все
пути протокола** — это сервер проброса из `chrome://inspect`, а не DevTools-эндпойнт.

Что работает: отдельный Chrome с отладкой и самописный драйвер CDP без зависимостей.

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9333 --user-data-dir=/tmp/chrome-agora \
  --no-first-run --no-default-browser-check
```

**Запускай его фоновой задачей harness (`run_in_background: true`)** — в обычном
вызове Bash процесс умирает вместе с вызовом, я на это попался дважды.

Драйвер: `scratchpad/cdp.mjs`, команды `open | text | probe | shot`.

```bash
node cdp.mjs text https://agora.185-154-194-125.sslip.io/studies
node cdp.mjs probe - 'document.querySelectorAll("svg").length'
node cdp.mjs shot https://agora.185-154-194-125.sslip.io/surveys /tmp/s.png
```

**Упирается в одно: профиль `/tmp/chrome-agora` чистый, и приложение уводит на
`/login`.** Пароль вводить нельзя — попроси владельца войти один раз в том окне,
дальше сессия держится в профиле.
