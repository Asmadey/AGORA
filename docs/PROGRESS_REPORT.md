## Что сделано сверх графа (с 05.08)

- **Найдена регрессия, которую спрятало общее объяснение.** Два теста воркера не
  запускались на машине исполнителя, и оба были списаны на среду. Один действительно про
  среду (`test_dependencies_declared` требует установленных fastapi, celery,
  faster-whisper, scenedetect), второй — нет: `test_pipeline` перечислял qa и analytics
  как ненаписанные и требовал от них `StageNotImplemented`. CI поймал это на PR #42.
  Урок записан в `loop-state.json`: одно объяснение на два падения — это гипотеза, а не
  вывод.
- **`StageNotImplemented` получил границу употребления.** Оно означает «этапа нет», а не
  «входа нет»: по первому читающий лог идёт искать ненаписанную задачу вместо
  отказавшего предыдущего узла. Проверка переписана так, чтобы пережить исчезновение
  последней заглушки.
- **Проверка #26 «тексты в засеве совпадают с файлами» сверяла только миграцию 07** и
  покраснела бы навсегда при любом обновлении дефолта промпта. Теперь сверяется последнее
  по счёту присвоение шаблона среди всех засевов.
- **`DEFAULT_ESCALATION_CONFIDENCE` расходился с `.env.example`** (0.7 против 0.6). Порог
  зависел бы от того, скопировал ли оператор файл. Сведены, совпадение держится тестом.
- **Размер отчёта замерен, а не прикинут** — от него зависит выбор хранилища:

  | | агрегат + синтез | + карточки персон |
  |---|---|---|
  | 100 персон × 1 | 1,2 КБ | 132 КБ |
  | 500 персон × 1 | 1,2 КБ | 654 КБ |
  | 500 персон × 3 | 178 КБ | **2,1 МБ** |

  Отсюда две коллекции в Mongo вместо одной и отказ от `jsonb` в `tasks`: эту таблицу
  сканирует список прогонов.

### Как повторить прогон

```bash
# на сервере, из /root/AGORA
set -a; . ./.env.local; set +a
export BASE_URL=https://agora.185-154-194-125.sslip.io
export DATABASE_URL="${DATABASE_URL/@postgres:/@127.0.0.1:}"   # имя docker-сети с хоста не резолвится
for f in evals/tests/test_task*.py; do python3 "$f" >/dev/null || echo "FAIL $f"; done
```

Тесты воркера (#13, #15, #16, #18, #19, #20) так гонять **нельзя** — их зависимости живут
в контейнере, и на python хоста они дают `ModuleNotFoundError`, неотличимый от дефекта
кода. Для них — разовый контейнер из образа воркера:

```bash
docker run --rm --network agora_default --env-file /root/.env.clean \
  -v /root/AGORA:/repo -w /repo agora-worker python evals/tests/test_task19_qa.py
```

`.env.clean` — копия `.env.local` со снятыми кавычками: `docker run --env-file` их не
снимает, в отличие от `docker compose`, и `WHISPER_COMPUTE_TYPE` приезжает как `"int8"`.
