# START HERE — AGORA

Точка входа для нового диалога или нового агента. Прочитай этот файл первым.

Он намеренно **не содержит статуса**. Статус живёт в трёх местах, и только в них:

| Что | Где | Формат |
|---|---|---|
| Прогресс по задачам | `evals/state/tasks.json` | граф, поле `status` |
| Что выяснено проходами | `loop-state.json` | `did` / `verdict` / `findings` / `failed_hypotheses` / `next` |
| Человеческая сводка | `docs/PROGRESS_REPORT.md` | таблицы, блокеры, ближайшие шаги |

Причина такого разделения — не аккуратность, а опыт: статус, скопированный во второй
документ, устаревает молча. Через месяц два файла рассказывают разное, и какой из них
свежее, по содержимому не видно. Этот файл раньше сам был таким: он сообщал «Pass 1
завершён» спустя двадцать три прохода.

**Если правишь статус — правь в трёх местах выше и больше нигде.**

## Что это за проект

Self-host мультиарендный сервис синтетических фокус-групп. По соцдем-параметрам
генерируется аудитория AI-персон, они «смотрят» видео и выдают аналитический отчёт
(5 критериев 1–10, NPS, ретеншн, эмоции, групповой синтез) — усреднённо и по каждой
персоне.

Заземление двойное: на grounding-корпус (165 карточек реальных респондентов из
XLS-анкет и DOCX-стенограмм) и на факты видео (транскрипт, диаризация, разбор сцен).
Позиционирование — «прогноз, а не догадка», и отчёт обязан нести дисклеймер о том, что
это гипотезы, требующие экспертной проверки.

## TL;DR технических решений

Qwen 3.6 через OpenAI-совместимый API timeweb (VLM и персоны) · Whisper large-v3 и
pyannote self-host на CPU · оба режима видео, `e2e_short` первым гейтом · Valkey + Celery
+ SSE, LangGraph внутри Celery · монорепо `apps/web` + `services/agent-core` +
`packages/shared` · PySceneDetect, панели по 4 кадра, кэш разбора · 8-категорийная Persona
DNA (Big Five 1–5) · групповой синтез, а не AI-модератор · Auth.js «команда = арендатор» +
RLS с `FORCE` на всех таблицах · «Перекрытие» (replication) и golden-сеты ×3 · петлю
гоняет исполнитель в среде пользователя (вариант B).

**Сквозной принцип, к которому пришли на #19 и #20:** арифметику считает код, модели
остаётся то, чего код не умеет. Средние, NPS, таймкоды за пределами ролика, внутренние
противоречия ответа — это проверяемо и должно быть детерминированным. Модель нужна там,
где нужно суждение: согласуется ли ответ с характером персоны, какие темы звучат, где
аудитория расходится.

Побочное следствие оказалось важнее замысла: детерминированный слой работает без ключа
провайдера, то есть в CI и на ноутбуке.

## Что нужно от пользователя

Актуальный список — в `docs/PROGRESS_REPORT.md`, раздел «Открытые блокеры». Здесь только
то, что не меняется:

- Доступы передаются SSH-ключами и одноразовыми ссылками, не текстом. Всё, что попало в
  переписку, считается скомпрометированным и требует перевыпуска (§6-бис `CLAUDE.md`).
- Каталог `docs/Evaluative research/` держится вне git.
- Статус задачи в графе ставит владелец по прогону в своей среде, а не автор кода (§4).
